# **App Name**: VideoVault

## Core Features:

- Video Recording: Opens the device's camera, allowing users to record videos.
- Video Gallery: Saves recorded videos locally within the app and displays them in a gallery.
- Video Merging: Allows users to select multiple videos from the gallery and merge them into a single video file.

## Style Guidelines:

- Primary color: Dark blue (#1A237E) for a professional look.
- Secondary color: Light gray (#E0E0E0) for backgrounds and subtle contrasts.
- Accent: Teal (#009688) for interactive elements and highlights.
- Grid layout for the video gallery to display videos in an organized manner.
- Use simple and clear icons for actions like recording, merging, and deleting videos.
- Smooth transitions between the camera view, gallery, and video merging screens.
